## Other delivered work

- opencode-tools `opencode-patch-rig.ts` with `_lib/opencode-patch-rig/` and
  `tests/opencode-patch-rig/` (`cb63d66`, then `41f09c2`): one command, `bun opencode-patch-rig.ts --all`.
  Levels `apply` (cherry-pick the branch's stack onto each base in a scratch
  `git clone --shared`), `test` (typecheck `packages/tui` against the vanilla
  error count, run the test files the stack changed with a scratch `HOME`),
  `tui` (scenarios in a real TUI on a throwaway tmux server, v1 one process,
  v2 a loopback `serve --stdio` pair, fake OpenAI-compatible provider, every
  scenario also run vanilla). A patch's `v2` port branch is tested in its
  place on v2. 27 scenarios.
