## Goals and constraints

- Observe exact native draft state and readiness without editing, focusing or submitting input.
- Preserve decoded input, paste metadata, logical tab ownership and native selection across pre-layout admission and startup handoff.
- Select crossed character boundaries consistently in the temporary startup and final editors.
- Keep native display-cell offsets and directional endpoints. Do not normalize ranges, pace keys, replace decoding, change library defaults or convert v1 UTF-16 drafts.
- This delivery adds no persistent native store or write/restore API. The related [v1 read/replace feature](./2026-09-27-tui-composer-read.md) has a separate contract.

## Public behavior

`ctx.ui.composer` is optional. `current()` is reactive; `subscribe(listener)` emits synchronously and on changes, with idempotent disposal and actual owner/plugin/TUI cleanup. `ComposerObservation` is ready only for the mounted selected final composer, with Home `sessionID: null`, or unavailable with `unsupported`, `not-mounted`, `not-selected` or `disposed`. The early editor and form/question inputs do not replace that owner.

The detached deeply readonly draft retains exact text, optional file attachments, agents, skills, pasted text/source metadata, mode, caret and `{ anchor, focus }`. Offsets are native edit-buffer display cells under the renderer's width/tab/control method plus one per newline. They are neither UTF-16 indices nor byte offsets. Startup and final editors consume one supported boundary policy; no OpenTUI default is changed.

## Cold-submit behavior

One Prompt-owned intent retains explicit Enter while required catalogs load and coalesces repeated/startup/native submissions. Known agent/model/variant identity is captured at Enter; unresolved Home uses existing normal default resolution. The bound pair is displayed before consumption, never rebound and reused for the actual submission. Warm usable selection does not wait for unrelated metadata.

Observed text/files/agents/skills/pasted/mode changes cancel, including a multi-chunk edit followed by revert; a single chunk ending byte-identical may send once. Caret/selection movement does not cancel. User selection changes, owner/session/location changes and unmount cancel. Empty/error hydration keeps the draft and shows an error; failed admission uses existing restoration without retry. The read-only observation API is unchanged.

Pending status uses a dedicated full-width row above the unchanged plugin footer and disappears on admission, cancellation or terminal error. `Waiting for model list...` needs 25 content cells; narrower layouts use native truncation. Real 44/100-column geometry tests preserve textarea dimensions, full text, caret and selection. Preserve this row's priority and the shared admission owner during upstream integration; [the source and native record](../sessions/2026-11-15-native-tool-deferral.md#cold-submit-contract-and-verification) includes the physical Home-key follow-up without changing bindings here.
